# rd_archive — archiwum cross-review R&D

Archiwalne materiały z fazy R&D projektu DriftScope: cross-review koncepcji,
briefów i analiz SWOT przez różne modele AI (DeepSeek, GPT, Gemini, Kimi,
Mistral, Qwen) oraz wczesne wersje briefu i decision-prompty.

Pliki przeniesiono z dawnego katalogu `R&D/` (root repo) do
`docs/research/rd_archive/` — ujednolicenie z istniejącym `docs/research/`
(kolizja przeznaczenia) i normalizacja nazw do snake_case (znak `&`
w nazwie katalogu był uciążliwy w PowerShell/URL/CI).

Materiały mają charakter **historyczny** (kontekst decyzji architektonicznych),
nie są częścią pipeline'u ani kontraktu.
